# 卡片组件设计规范 Card Component Spec

## 一、组件概览

该卡片用于展示课程 / 社群内容，包含封面图、标签、标题、数据统计、简介描述和行动按钮。

- **尺寸**：314 × 426 px（固定）
- **圆角**：12px
- **背景**：#FAFAFB
- **描边**：Inside 0.5px · `rgba(99, 99, 99, 0.14)`（#636363 @ 14% 不透明度）

---

## 二、整体结构

```
Card (314 × 426)
├── Hero Image          ← 封面图区域
├── Tags (浮于图上)      ← 绝对定位标签列
└── Content             ← 内容区域
    ├── Headline        ← 标题
    ├── Stats           ← 数据统计行
    ├── Description     ← 简介文本
    └── CTA Button      ← 行动按钮
```

## 四、各层规范

### 4.1 封面图 Hero Image

```
尺寸：314 × 222 px
背景：#DEDEDE（图片未加载时占位色）
圆角：继承卡片顶部 12px（仅上方两角，由父级 overflow: hidden 裁剪）
布局：align-self: stretch，随卡片宽度拉伸
```

### 4.2 浮层标签组 Tags

```
定位：absolute，left: 24px，top: 179px
       （与内容区重叠 43px，营造悬浮感）
布局：flex-direction: row，gap: 8px
```

**单个 Tag：**

```
尺寸：60 × 31 px
内边距：8px 12px
背景：#FFFFFF
圆角：100px（完整胶囊）
字体：Source Code Pro Regular 12px / line-height: 15px
颜色：#3C3C43
布局：justify-content: center，align-items: flex-end
```

> ⚠️ `align-items: flex-end` 让文字贴近底部，与图片底边对齐时视觉更稳定。

### 4.3 内容区 Content

```
尺寸：314 × 204 px
内边距：24px（四边等距）
间距：gap: 16px（子元素纵向间距）
布局：flex-direction: column，align-items: flex-start
```

#### Headline 标题

```
字体：SF Pro Medium（weight 510），18px，line-height: 21px
颜色：#000000
```

#### Stats 数据统计行

```
布局：flex-direction: row，gap: 10px
```

| 子项 | 图标尺寸 | 文字样式 | 颜色 |
|---|---|---|---|
| 人数（人像 icon + 数字） | 18 × 18 px | Source Code Pro 14px | `#181818` |
| 浏览量（眼睛 icon + 数字） | 20 × 20 px | Source Code Pro 14px | `#181818` |

图标与数字间距：`gap: 4px`

#### Description 描述文字

```
宽度：272px（= 314 - 24×2 + 4px，注意边距修正）
最大行数：2 行（约 height: 36px）
字体：Source Code Pro Regular 14px，line-height: 18px
颜色：#666666
溢出处理：-webkit-line-clamp: 2
```

#### CTA Button 行动按钮

```
尺寸：80 × 31 px
内边距：8px 16px
背景：#3C3C43
描边：1px solid #3C3C43
圆角：12px
字体：Source Code Pro Regular 12px，line-height: 15px
文字颜色：#FFFFFF
```

## 七、注意事项

1. **标签悬浮定位**：Tags 使用 `position: absolute`，父容器需设 `position: relative`；`overflow: hidden` 设在 card 上，避免裁剪标签。
2. **字体回退**：SF Pro 仅 Apple 平台原生支持，Web 端使用 `-apple-system, BlinkMacSystemFont, sans-serif` 回退。
3. **图片圆角**：card 设有 `overflow: hidden`，Hero Image 无需单独设圆角，自动继承卡片圆角裁剪。
4. **描述截断**：设计稿固定 2 行高（36px），实现时建议用 `-webkit-line-clamp: 2` 而非固定高度，适配不同字体渲染精度。
